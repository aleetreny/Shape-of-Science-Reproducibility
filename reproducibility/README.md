# Reproduction entry points

See [the release guide](../README.md) and [coverage](../COVERAGE.md) for downloads, commands and exclusions. Version 1.1.0 is a compact statistical reproduction release. The old `check_vectors.py` and `verify_archives.py` programs describe the superseded full numerical archive layout; they are retained as historical source only and cannot run against this compact selection.

Use `reproduce_summaries.py` without dependencies, or `reproduce_analysis.py` after extracting the data archives and installing `requirements-analysis.txt`.
